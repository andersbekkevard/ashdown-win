Ashdown House, MIT Table tennis ladder
ashdown .win

Record a match. Watch the number move.

The public table tennis ladder for the house. No accounts: one name, one rating, and every match ever played on the record.

1
Create your name
Once. Full name by default; your MIT username if you prefer. You start at 1000.
2
Record a match
Two names, tap the winner. Doubles count at half weight. Anyone can file it.
3
Watch the board
Ratings are recomputed from the full log every time, so every number can be checked.
The rule
R′ = R + K (S − E),   E = 1 / (1 + 10(Ropp − R) / 400)
S is 1 for a win, 0 for a loss. K = 32 singles, 16 doubles. Everyone starts at 1000.
Scan, or type ashdown.win into any browser. Nothing to install, nothing to sign up for.
