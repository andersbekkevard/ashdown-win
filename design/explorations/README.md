# Design explorations

Nine parallel visual explorations for ashdown.win, produced 2026-09-07. Each
folder is self-contained and was made by a separate agent that did its own
visual research before choosing a style language.

Every folder contains:

- `brief.md` — the style language, the references studied, and the reasoning
- `poster.html` — an A4 portrait poster meant to explain and sell the ladder
- `app.html` — a mobile-first mockup of the site: home with leaderboard,
  record match, and a player page

All nine use the same fake data in `data.json` so they can be compared.
`index.html` links to everything.

| Folder | Style |
|---|---|
| `official-notice` | The house has always had an official rating |
| `irish-pub-ladder` | Club ladder on the wall of a Boston Irish pub |
| `one-word` | One enormous word, minimal typographic |
| `led-scoreboard` | Glowing digital stadium scoreboard |
| `whiteboard` | Something a grad student drew on a whiteboard |
| `lichess` | A faithful adaptation of the Lichess visual language |
| `fenway-monster` | Fenway Park's hand-set Green Monster scoreboard |
| `athena-terminal` | MIT Athena terminal, monospace command output |
| `fall-guys` | Fall Guys, loud and playful |
